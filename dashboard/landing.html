Core Capabilities

What SignSpeaker Provides

A complete end-to-end wearable stack spanning kinetic sensing, machine learning, telemetry, and multimodal feedback.

6-DoF Kinetic IMU Sensing

High-frequency polling of 3-axis angular velocity (ωx, ωy, ωz) from an MPU6050 sensor at 25 Hz (~40ms). Captures subtle hand dynamics without restricting fingers.

MPU6050 • I2C @ 25 Hz

Dual Untethered Telemetry

Works 100% untethered. Choose between Wi-Fi MQTT broker integration (cross-network / Mosquitto) or direct low-latency ESP-NOW 2.4 GHz radio (<5ms transmission).

Wi-Fi MQTT • ESP-NOW Radio

Dynamic Segmentation Engine

Continuous EWMA resting bias estimation (α=0.03) actively compensates for sensor drift, while a precision state machine isolates deliberate signs from involuntary resting tremors.

EWMA Bias • Rolling Pre-Roll

66-D Trajectory Machine Learning

Extracts 16 equidistant resampled 3D points, temporal duration, and per-axis statistics. Standardized Z-scores are classified via weighted k-NN (k=3) with outlier rejection.

Resampled Trajectory • k-NN

Persistent Zero-Latency TTS

Keeps Windows SpeechSynthesizer permanently warm via a background daemon. Eliminates the 1.5s cold-start CLI penalty, delivering crystal-clear instant vocal feedback.

System.Speech • Near-Zero Latency

Smart 16×2 LCD Word Wrapping

Autonomous text layout engine formats output onto physical and virtual dual-line displays, dynamically wrapping sentences along whitespace boundaries without breaking words.

HD44780 LCD • Auto-Wrap

System Pipeline

How SignSpeaker Works

From subtle inertial finger-wrist movements to spoken words in four seamless stages.

01

Inertial Capture

MPU6050 IMU samples 3D angular velocities at 25 Hz. Packets are streamed via Wi-Fi MQTT or ESP-NOW radio directly to the edge host.

02

Event Segmentation

Continuous EWMA filters out stationary bias. When motion exceeds 0.20 rad/s, trajectory buffers active samples until quietude is sustained.

03

Feature Extraction & k-NN

66 normalized features are extracted across 16 resampled points. Weighted k-NN (k=3) computes closest neighbors with statistical outlier rejection.

04

Multimodal Output

Recognized text is vocalized simultaneously via persistent TTS audio, wrapped onto the 16×2 LCD screen, and broadcasted to the web dashboard.
