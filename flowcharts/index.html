Diagram 02 DSP & Machine Learning

⚙️ Gesture Segmentation State Machine

Continuous 25 Hz motion segmentation with Exponentially Weighted Moving Average (EWMA) resting bias cancellation, 3-sample pre-roll buffering, and dual-mode parameter adaptation.

Source: node-red/functions/gesture-engine.js
flowchart TD
    SAMPLE_IN(["topic: 'sample' arrives
{t, dev, gx, gy, gz}"])

    SAMPLE_IN --> BIAS_CORRECT["Subtract EWMA Gyro Bias:
gx -= bias.x
gy -= bias.y
gz -= bias.z
(α = 0.03 updates only in WAITING state)"]
    BIAS_CORRECT --> CALC_MAG["Calculate Angular Magnitude:
mag = √(gx² + gy² + gz²)"]
    CALC_MAG --> CHECK_PHASE{Current State Phase?}

    %% COOLDOWN STATE
    CHECK_PHASE -->|cooldown| COOLDOWN_CHECK{"now >= cooldownUntil?
(700ms Word / 800ms Sentence)"}
    COOLDOWN_CHECK -->|No| DROP[Drop sample: in cooldown]
    COOLDOWN_CHECK -->|Yes| SET_WAITING["phase = 'waiting'
Notify UI via WebSocket"]
    SET_WAITING --> WAIT_BLOCK

    %% WAITING STATE
    CHECK_PHASE -->|waiting| WAIT_BLOCK["Track EWMA bias (if mag < start)
Append sample to Pre-roll buffer
(Maintains last 3 samples)"]
    WAIT_BLOCK --> ONSET_CHECK{"mag > start threshold?
(0.20 rad/s Word / 0.18 rad/s Sentence)"}
    ONSET_CHECK -->|No| DROP2[Await next sample]
    ONSET_CHECK -->|Yes| ONSET["phase = 'active'
buf = preRoll + current sample
startT = now
quietSince = 0"]

    %% ACTIVE STATE
    ONSET --> ACTIVE_BLOCK
    CHECK_PHASE -->|active| ACTIVE_BLOCK["Append sample to trajectory buf"]
    ACTIVE_BLOCK --> END_CHECK{"mag < end threshold?
(0.12 rad/s Word / 0.11 rad/s Sentence)"}
    END_CHECK -->|No: Active movement| QUIET_RESET[quietSince = 0]
    QUIET_RESET --> MAX_CHECK
    END_CHECK -->|Yes: Hand slowing down| QUIET_TIMER["quietSince = timestamp (if not set)"]
    QUIET_TIMER --> QUIET_DONE{"Quiet for >= quiet duration?
(250ms Word / 420ms Sentence)"}
    QUIET_DONE -->|Still quiet, within window| MAX_CHECK
    QUIET_DONE -->|Yes: Gesture completed!| FINISH_GESTURE

    MAX_CHECK{"Duration >= maxTime?
(1500ms Word / 4500ms Sentence)"}
    MAX_CHECK -->|No| DROP3[Await next sample]
    MAX_CHECK -->|Yes: Maximum timeout reached| FINISH_GESTURE

    %% FINISH & EMIT
    FINISH_GESTURE["Compute duration = endT - startT
Trim buffer to samples <= endT"]
    FINISH_GESTURE --> MIN_CHECK{"duration >= minTime?
(120ms Word / 300ms Sentence)
AND sample count >= 3?"}
    MIN_CHECK -->|No: Accidental twitch/noise| DISCARD_GESTURE["Discard burst
Emit 'discarded' event
phase = 'waiting'"]
    MIN_CHECK -->|Yes: Valid gesture!| EMIT_GESTURE["Emit topic: 'gesture'
{at, duration, samples[ [dt,gx,gy,gz] ], mode, label}
Forwarded to Dataset & Model"]

    EMIT_GESTURE --> ENTER_COOLDOWN["phase = 'cooldown'
cooldownUntil = now + cooldownDuration"]
Engine Parameter Word Mode (Default) Sentence Mode Mathematical Role
Start Threshold 0.20 rad/s 0.18 rad/s Motion energy $\sqrt{gx^2+gy^2+gz^2}$ required to trigger onset
End Threshold 0.12 rad/s 0.11 rad/s Upper bound marking quiet decelerating motion
Quiet Duration 250 ms 420 ms Continuous stillness required before triggering gesture completion
Minimum Duration 120 ms 300 ms Rejects accidental finger twitches and vibration artifacts
Maximum Duration 1500 ms 4500 ms Forced timeout to finalize long multi-word expressions
Cooldown Duration 700 ms 800 ms Locks out onset while the user returns hand to resting position
Pre-roll Buffer 3 samples 3 samples Prepends ~120ms of samples prior to threshold trigger
Diagram 03 DSP & Machine Learning

🧠 66-D Feature Extraction & Weighted k-NN Classifier

Transforms raw variable-length trajectory bursts into a standardized 66-dimensional vector, evaluated by a distance-weighted k-NN ($k=3$) with statistical outlier rejection.

Source: node-red/functions/dataset-model.js
flowchart TD
    GESTURE_IN(["topic: 'gesture' arrives
{mode, recording, label, samples[ [dt,gx,gy,gz] ]}"])

    GESTURE_IN --> CHECK_MODE{Engine Mode?}

    %% TRAINING RECORDING
    CHECK_MODE -->|train & recording=true| SAVE_SAMPLE["Append sample to dataset.json:
{id, label, at, duration, samples}
Atomic write via temp file + renameSync"]
    SAVE_SAMPLE --> BUMP_REV["ds.rev++
Update UI sample inventory counts"]
    BUMP_REV --> EXTRACT_PIPELINE

    %% RECOGNITION / INFERENCE
    CHECK_MODE -->|recognize| EXTRACT_PIPELINE
    CHECK_MODE -->|train & preview only| EXTRACT_PIPELINE

    EXTRACT_PIPELINE["Extract 66-Dimensional Feature Vector:"]
    EXTRACT_PIPELINE --> F_DUR["Feature [0]:
Total Gesture Duration (seconds)"]
    EXTRACT_PIPELINE --> F_AXIS["Features [1-15]: Per-Axis Statistics (X, Y, Z)
Range, Mean, Standard Deviation, Mean Abs, Peak"]
    EXTRACT_PIPELINE --> F_MAG["Features [16-17]: Magnitude Statistics
Mean Magnitude & Peak Magnitude"]
    EXTRACT_PIPELINE --> F_TRAJ["Features [18-65]: Resampled Trajectories
16 Equidistant Linear-Interpolated Points × 3 Axes"]

    F_DUR & F_AXIS & F_MAG & F_TRAJ --> ASSEMBLE_VEC["Assemble 66-D Feature Vector X"]

    ASSEMBLE_VEC --> MODEL_CHECK{Trained k-NN Model Exists?}

    %% RULE-BASED FALLBACK
    MODEL_CHECK -->|No Model Trained| RULES["classifyRules()
Compute Axis Ranges {x, y, z}:
• Hello: x>0.70 & y>0.40 & z>0.50
• I am: y>0.65 & y>1.15*x & y>1.15*z
• Reem: x<0.30 & y<0.30 & z<0.30
• Thanks: z>0.70 & x>0.25 & z>y
• Else: Unknown"]
    RULES --> PRED_ASSEMBLE

    %% k-NN INFERENCE
    MODEL_CHECK -->|Yes: Trained Model Ready| ZSCORE["Standardize Vector (Z-score):
z_i = (x_i - mean_i) / std_i"]
    ZSCORE --> KNN["Calculate Euclidean Distances to All Training Points
Find top k = 3 nearest neighbors
Weight votes: w = 1 / (distance + 0.001)"]
    KNN --> REJECT_DIST{"Nearest neighbor distance <=
model.rejectDistance?
(1.5 × 95th-pct same-class distance)"}
    
    REJECT_DIST -->|Exceeds: Novel / Outlier Gesture| OUTLIER["known = false
Label = 'Unknown'"]
    REJECT_DIST -->|Within Boundary| CONF_CHECK{"Confidence >= minConfidence?
(Default: 0.55)"}
    
    CONF_CHECK -->|Below Threshold| LOW_CONF["known = false
Label = 'Unknown'"]
    CONF_CHECK -->|Passes All Checks| WIN_PRED["known = true
Label = Winning Neighbor Class"]

    OUTLIER & LOW_CONF & WIN_PRED --> PRED_ASSEMBLE

    PRED_ASSEMBLE["Assemble Final Prediction Object:
{label, known, confidence, distance, votes, source}"]

    PRED_ASSEMBLE --> DISPATCH_RESULTS["Out 1: 'gesture' telemetry → WebSocket Dashboard
Out 2 (recognize only): 'prediction' → Output Dispatcher
Out 3 (training only): 'write' LCD update → Serial"]
Feature Index Group Name Count Mathematical Definition
0 Gesture Duration 1 $T = (t_{\text{end}} - t_{\text{start}}) / 1000$ (seconds)
1 – 5 Gyro X Stats 5 Range ($\max - \min$), Mean ($\mu$), Std Dev ($\sigma$), Mean Abs, Peak
6 – 10 Gyro Y Stats 5 Range ($\max - \min$), Mean ($\mu$), Std Dev ($\sigma$), Mean Abs, Peak
11 – 15 Gyro Z Stats 5 Range ($\max - \min$), Mean ($\mu$), Std Dev ($\sigma$), Mean Abs, Peak
16 – 17 Magnitude Stats 2 Mean and Peak of $\|G\| = \sqrt{gx^2 + gy^2 + gz^2}$
18 – 33 Trajectory Gyro X 16 16 equidistant points linearly interpolated across gesture time
34 – 49 Trajectory Gyro Y 16 16 equidistant points linearly interpolated across gesture time
50 – 65 Trajectory Gyro Z 16 16 equidistant points linearly interpolated across gesture time
Total Full Feature Vector 66 Standardized via dataset $z = (x - \mu) / \sigma$

    PRED_IN --> GATE_CHECK{"known == true

(Default: 0.55)"}
    GATE_CHECK -->|Pass| ACCEPT_LABEL[text = p.label]
    GATE_CHECK -->|Fail| REJECT_LABEL["text = 'Unknown'"]

    %% LCD PATHWAY
    ACCEPT_LABEL --> LCD_ACTIVE{lcd enabled?}
    REJECT_LABEL --> LCD_ACTIVE

    LCD_ACTIVE -->|Yes| FORMAT_LCD{"text === 'Unknown'?"}
    FORMAT_LCD -->|Yes| LCD_UNK["Command: 'W,Unknown'

    FORMAT_LCD -->|No: Valid text| LENGTH_CHECK{"text.length <= 16?"}
    
    LENGTH_CHECK -->|Short Word| SHORT_W["Command: 'W,' + text
Displays on Line 1 with status on Line 2"]
    LENGTH_CHECK -->|Long Sentence| SMART_WRAP["Smart Word Boundary Algorithm:
Split text by spaces
Pack Line 1 up to 16 chars
Pack remainder onto Line 2

    LCD_ACTIVE -->|No| LCD_NULL[LCD Output Disabled]
    LCD_UNK & SHORT_W & SMART_WRAP --> LCD_DISPATCH["Send to Serial Manager:

    %% AUDIO SPEECH PATHWAY

    CHECK_UNKNOWN -->|Yes & speakUnknown=true| SPEAK_UNKNOWN["Spoken phrase: 'Unknown gesture'"]
    CHECK_UNKNOWN -->|No: Valid word| SPEAK_VALID["Spoken phrase = text"]

    SPEAK_ACTIVE -->|No| SPEAK_DISABLED[Speech Output Disabled]

    SPEAK_UNKNOWN & SPEAK_VALID --> TTS_SEND["Send topic: 'say'
Forward to persistent speaker.js daemon"]

    %% UI TELEMETRY
    ACCEPT_LABEL --> UI_NOTIFY
    REJECT_LABEL --> UI_NOTIFY
    UI_NOTIFY["Emit topic: 'output'
{text, confidence, spoken, lcdSent, at}

Step Mathematical Formula Implementation Notes
1. Standardization $z_{i} = \frac{x_{i} - \mu_{i}}{\sigma_{i}}$ Features normalized to zero-mean, unit-variance using training set $\mu$ and $\sigma$.
2. Distance Metric $d(u, v) = \sqrt{\frac{1}{66} \sum_{i=1}^{66} (u_i - v_i)^2}$ Normalized Euclidean distance across all 66 standardized dimensions.
3. Weighted Voting $w_j = \frac{1}{d_j + 0.001}$ Closer training examples contribute exponentially higher voting weight.
4. Outlier Threshold $\text{RejectDist} = 1.5 \times P_{95}(\text{LOO Distances})$ Adaptive rejection radius: 1.5 times the 95th-percentile leave-one-out nearest distance.
